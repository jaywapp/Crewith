# 성능·안정성 설계

정상 입력의 반환값·순서·오류 계약을 유지한다. 반복 순회를 합치거나 호출 내 중간 값을 재사용하며 전역 데이터 캐시로 최신성을 바꾸지 않는다. 외부 입력의 오류는 기존 실패 응답 또는 예외로 전달하고 성공으로 숨기지 않는다. 테스트에는 중립적인 fixture만 사용한다.

검증: 저장소 기존 테스트 도구를 우선 사용하고, 설치 상태와 외부 서비스 의존 때문에 실행 불가능한 검증은 별도로 명시한다.


## 입력 경계 보강

일정·회비·공지 생성의 필수 문자열과 참석/출석 enum을 공통 검증한다. 컨트롤러에서 두 저장소 구현으로 진입하기 전에 검증하므로 JSON·Prisma에 동일하게 적용된다. 검증 실패 로그는 operation/field만 남기고 요청 본문·회원 정보는 출력하지 않는다. 기존 정상 엔드포인트 및 인증 403 테스트와 새 400/무변경 테스트를 실행한다.
